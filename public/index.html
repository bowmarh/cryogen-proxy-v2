🤝 Fair play

Our verification standard

CRYO-GEN riders racing ZRL/WTRL events should keep a second recording running as a backup (a bike computer or a second device) in case verification is requested.

We may occasionally ask for a file as routine housekeeping. It's nothing personal if you're asked, and it's the same for everyone. Racing clean is what keeps the results worth having.

If we ask for a file

Just send it to a ride leader or an admin in a Discord DM. That's all there is to it.
